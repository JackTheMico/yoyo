# 麓鸣输入法

> *呦呦鹿鸣，食野之苹。*

麓鸣——一款兼顾极简规则和极致性能的顶功并击输入法。

本项目包含麓鸣（YoYo）输入方案的 Rime 配置以及用于展示和练习字根的 HTML 可视化工具。

## 两支方案，选一个开始

麓鸣分**纯形**与**音形**两支。两支共用同一张字根表和同一套并击理念，但**码元空间、取码规则、打法全都不同**，装好后在方案选单（`Control+Tab`）里切换。


|       | 纯形·麓鸣                               | 音形·呦呦                                   |
| ----- | ----------------------------------- | --------------------------------------- |
| 方案    | `yoyo-bm`（北冥／单字派）、`yoyo-wx`（无相／主词派） | `yoyo-yx`                               |
| 一句话   | 纯形码、字词混打、三码定长、60 码元、双编码（大码小码皆键位）  | 音形混合、字词由第一击分流、单字三码定长／词四码定长、180 码元       |
| 单字第一码 | 字根                                  | **音节**（声母 + 韵母）                         |
| 需要背   | 字根表                                 | 字根表 + 声韵母分组                             |
| 亮点    | 【6638 字全码零重码】、支持 10w 汉字扩展字集         | 【4684 字两码零重码】、【124 万词四码零重码】、【700 个一击直出】 |
| 适合    | 想要纯形的确定感、不依赖读音                      | 会拼音、想靠读音降低入门门槛、打词爽                      |


- 纯形看 [「麓（lù）鸣」的优势](#麓lù鸣的优势) 起，到[主词派——「无相」](#主词派-无相)止。
- 音形看 [音形分支——「呦呦」](#音形分支-呦呦)一节，它是独立完整的介绍，不必先读纯形部分。

## 「麓（lù）鸣」的优势：

> *追求并击的上限。*

> 本节到「无相」为止，讲的都是**纯形**支（`yoyo-bm` / `yoyo-wx`），下列数字均为纯形数据。音形支的规则和数据在[音形分支——「呦呦」](#音形分支-呦呦)一节单独给出。

1. 极低击长（“击长”概念类比串击的“码长”）：
  - 单字最高码长为三码（分两击打出）；
    - 【一击】字（只需一次并击即可打出的字）加权占比为【94.3%】！
    - 一击顶功——继承并击独特的顶功优势，单字无需空格即可上屏。
2. 极低重码：
  - 单字前6638字【全码无重】！简码和全码都是零重码（6638字指GB2312和《通用规范汉字表》收录字符的交集）。
    - 前 60000 高频词，加权重码率只有【0.25%】！
    - 一击词和一击字打法不同，所以编码无重叠。
3. 思维负担低：
  - 相比其他并击方案，【指法更简单】。
  1. 按键更省力：单手最多同时按两个键来确定一个码元；
  2. 指法更固定：只需记住基于QWERT五个键的指法，通过平移和镜像的推理即可记住其它码位。
    其他形码，大字根，【拆分直观】。
    质是三码定长的形码方案，相比其他顶功方案，【打字规则简单】。
4. 独一无二的爽点：
  1. 100% 的确定感——单字零重，词重极低。
  2. 一键上屏字/词（30 个）
    只按一个键即可上屏（可能是单字，也可能是词），无需空格。
      同一键位如果同时安排了字和词，则按使用频率决定首选顺序；需要第二个候选时可用 `'` 选二选。
    - 对照：普通串击顶功，这样的一键字只有 5~8 个。
    - 此外，单手一击字共【120 个】，算上双手的一击字，共【2152 个】。



## 心法「形码基础」：如何打出一个字

如果你是第一次接触形码/并击，先记两句话就够用：

1. 汉字会被拆成若干「字根」，每个字根都有自己的编码。
2. 麓鸣打单字只取三个字根来编码：第一根、第二根、最后一根（所以单字最高三码）。



### 你需要知道的编码长相

- 每个字根是「双编码」：大码 + 小码，两者都是**码元键位**
  - 大码：该字根所在的键位（第一码）
  - 小码：该字根的第二码（本版键位重排，小码也随大码一并移位，不再是音托字母）

示例：字根「鹿」的双编码是 `kS`，其中 `k` 是大码、`S` 是小码。

### 单字取码规则（只看这一段就能开始打）

为了让单字固定为三码，麓鸣按字根数量分三种情况：

- 单字根字：全码就是该字根的双编码
  - 例：`鹿 = kS`
- 双字根字：取第一根大码 + 第二根大码 + 第二根小码
  - 例：`鸣 = tag`（口 `tH`，鸟 `ag`）
- 多字根字：取第一根大码 + 第二根大码 + 最后一根大码
  - 例：`德 = yKq`（彳 `ye`，十 `Ku`，心 `qE`）



### 术语速查（看懂本文后面两套打法）

- 字根：把字按书写结构拆出来的部件。
- 码元：编码里允许出现的基本符号（一般为 a-z、数字、`;,./` 等符号）；并击可用组合键扩展码元集合（如加入 A-Z、`:<>?` 等）。
- 双编码：一个字根对应两位字母（大码 + 小码）。
- 简码：用更短的码直接打出的高频字/词（常见说法：一简、二简等）。
- 顶功 / 顶字上屏 / 顶屏：继续输入下一键时，候选框当前选中项会自动上屏。
- 并击：一次同时按下多个键，输出一个或多个码元。
- 串击：一次按一个键（或按键序列）逐个输入。



### 简码、顶功与选重（新手最常用）

字和词都设有一简、二简，词还有三简。

- 一简字示例：的 → `d`
- 一简词示例：什么 → `a`

一简/二简输入后，不需要空格确认：下一键会触发顶屏，默认上屏首选。

若候选不是首选，按 `'` 选二选并立即上屏（一简没有设三选）。

### 如何打出一个词（全码取码规则）

构成词的基本单位是单字。

词的全码是四码定长，可按下面规则从组成单字的编码中取出。

- 二字词：第一个字的前两码 + 第二个字的前两码
- 三字词：第一字首码 + 第二字首码 + 第三字前两码
- 四字词：第一二三四字的首码

## 纯形指法「六脉神剑」：平移&镜像

**指法更固定：** 每一行码元的指法都是一致的。只需记住基于 QWERT 五个键的指法，通过平移和镜像的推理即可记住其它码位。

六脉神剑指法

### 变体「空明拳」：照搬空明码键位

**指法结构：** 60 码元 = 15 单键（`qwertasdfgzxcvb` 直出）+ 45 双键（大写、部分小写、符号，单手双键并击）；另有 5 个数字码元（`0 6 7 8 9`）用字母+符号双键打出（如 `q+a→0`）。「空明拳」（英文标识 `yoyo-km`）是六脉神剑的变体，键位照搬空明码：大写用双字母键打出（如 `q+v→Q`），数字码元用字母+符号双键，整段不再用数字行。左右手镜像为 QWERTY 同排水平对称（`y→t` 等），同一码元左右手都能打出。定义在 `rime/yoyo.yaml` 的「空明拳」段，可用 `__include: yoyo:/空明拳` 引用。

## 字/词打法「两套功法」：充分发挥顶功特性



### **集合分组和定义：**

> 不同的按法会进入不同的“输入通道”，本文用 `A/a/B/b/C/c` 来区分它们。
>
> 记法约定：大写表示不按 `Space`，小写表示带 `Space`；`A/a` 是双手并击，`B/b` 是左手单手并击，`C/c` 是右手单手并击。
>
> 直观理解：双手并击一击输出两码，单手并击一击输出一码（是否带 `Space` 不改变码数，只改变通道/用途）。

不同的集合可以用来打出不同的对象。以「北冥」为例（后面会详细介绍）：

1. 双手并击为集合 `A`：打两码及以上的字
2. 单左手为 `B`：打一简字
3. 单右手为 `C`：打一简字
4. 单左手带 `Space` 并击为 `b`：打单字的第三码（左右结构 `⿰`，如“鸣”；或左下包围 `⿺`，如“爬、过”）
5. 单右手带 `Space` 并击为 `c`：打单字的第三码（除 `⿰`/`⿺` 之外的结构）
6. 双手带 `Space` 并击为 `a`：打词（四码定长，含一击简词）
  —*通过增加结构筛选，单字最多只需三码，即可实现 6638 字集的全码无重。*

---

下面是两个功法的设计。

### 单字派 **——「北冥」：**

> *段誉所赠，逍遥派绝学。逍遥武功，以积蓄内力为第一要义；内力既厚，犹之北冥，天下武功无不为我所用*
>
> *打法：并击主单。为麓鸣完全体功法，专为打单的「爽点」打造。*

1. 打单：`A` 为第一击，一击若没出首选，则补一个 `b/c`，再之后的下一键触发顶屏上屏（`A` 一旦出现则会顶屏候选框中的内容）；
2. 打词：如果 `a` 作为第一击，则只会打词。词为四定（四码定长）模式：输入完四码后，开始输入下一键时触发顶屏上屏，词的第三、四码可以用 `b/c` 打出，也可以再用 `a` 一次性打出。
3. `B/C` 直出一简字/词，按下后会立即上屏（等价于触发一次顶屏）。



#### 例子：打单字（以“鸣”为例）

已知：`鸣 = bXn`，且“鸣”为左右结构 `⿰`（口 + 鸟），所以第三码走通道 `b`。

1. 第一击：用 `A` 输出前两码 `bX`。
2. 若候选首选已是“鸣”：继续输入下一键（例如下一个字/词的第一键），触发顶屏，“鸣”自动上屏。
3. 若首选不是“鸣”：用 `b` 补第三码 `n`（结构筛选 + 补码），再继续输入下一键触发顶屏，“鸣”上屏。



#### 例子：打词（以“动物园”为例）

已知：“动物园”的三简为 `NmU`，全码（四码）为 `NmUE`。

1. 第一击：用 `a` 输入前两码 `Nm`。
2. 第二击：用 `b或c` 输入第三码 `U`。
3. 若候选不是首选：按 `'` 选二选（如 `NmU'` 或 `NmUE'`），立即上屏。

  ——通过第一击的打法不同，可将字词编码完全分离。*



### 主词派 **——「无相」：**

> *逍遥李秋水亲授。适配兼容，顺逆自如，不着形相，精微渊深。*
>
> *打法：并击主词，可随时连击。*
>
> - *并击连击可无缝转换：单手连击减少了思维压力，可作为双手并击的过渡；*
> - *对主词派来说，无相既是「过渡体」，也是「究极体」。*

1. 打词：`A` 为第一击，一击若没出首选，则可选补 `B` 或 `C`（一码一码地出）或 `A`（直出两码）；每输入满四码，下一键触发顶屏上屏。
2. 打单字：
  - 前两码：可选 `B` 或 `C` 连击，一码一码地出，左右手均可；或以 `a` 为第一击，直出前两码
    - 第三码：`b` 或 `c` 补第三码。`b` 打 `⿰`/`⿺` 结构的字，`c` 打其他结构的字。
3. 第一击为 `b/c` 直出一简字词



#### 例子：打单字（以“鸣”为例）

已知：`鸣 = KXn`，且“鸣”为左右结构 `⿰`，所以第三码走 `b`。

- 方案 2（双手起手）：`a` 先出前两码 `KX` → `b` 补 `n` → 继续输入下一键触发顶屏，“鸣”上屏。

已知：“动物园”的三简为 `NmU`，全码（四码）为 `NmUE`。

2. 第二击：用 `b或c` 输入第三码 `U`。

4. 若候选不是首选：按 `'` 选二选（如 `NmU'` 或 `NmUE'`），立即上屏，或继续用 `b或c` 输入第四码 `E`。

## 音形分支 **——「呦呦」：**

> *呦呦鹿鸣，好听好听*
>
> *打法：并击主词。为麓鸣的音形分支，专为打词的「爽点」打造。一击两个字，思维更流畅*

「呦呦」不是前面两套功法的第三种打法，而是**换掉了取码规则**的独立分支：单字的第一码由字根改成了**音节**，所以叫「音形」。字根沿用同一张字根表，但码元空间从 60 个扩到 180 个，编码全不一样——上面「北冥 / 无相」的所有编码示例在这里都不适用，本节独立完整，不必先读纯形部分。

一句话描述：音形混合、字词由第一击分流、**单字三码定长 / 词四码定长**、180 码元、【4684 字两码零重码】、【50 万词四码零重码】、【700 个一击直出】的中文并击输入方案。

### 心法「音形基础」：一码 = 一个码元 = 一次单手并击

呦呦的最小单位是**码元**，写作两个字母：

```
码元 = 声母键（小写，15 个：qwert asdfg zxcvb）+ 韵母指法（大写，12 个：A–L）
```

15 × 12 = **180 个码元**。这 180 个码元既用来写音节，也用来写字根。

- **一次单手并击 = 一个码元。** 如按 `q` 出 `qA`，`2`+`q` 出 `qB`，`q`+`w` 出 `qF`。
- **左右手镜像对称**，两只手都能打出全部 180 个码元（右手 `y u i o p [ h j k l ; n m , .` 依次镜像到左手 `b t r e w q g f d s a v c x z`）。
- **一次双手并击 = 两个码元 = 四个字母**，这就是「一击两个字」。

> 下文说「几码」，一码即一个码元、两个字母。所以单字全码是六个字母、词全码是十二个字母。



#### 声母 → 键位（15 组）


| 键   | 声母   | 键   | 声母  | 键   | 声母    |
| --- | ---- | --- | --- | --- | ----- |
| `q` | m ch | `w` | c w | `e` | p sh  |
| `r` | b    | `t` | f x | `a` | n zh  |
| `s` | h    | `d` | d r | `f` | y     |
| `g` | z q  | `z` | t   | `x` | g     |
| `c` | l    | `v` | k j | `b` | s、零声母 |




#### 韵母 → 指法（12 组）


| 指法  | 韵母            | 指法  | 韵母                  | 指法  | 韵母           |
| --- | ------------- | --- | ------------------- | --- | ------------ |
| `A` | ang ia ua ve  | `B` | ng en ie uo         | `C` | ou u         |
| `D` | ao ian        | `E` | i                   | `F` | ing e        |
| `G` | uai a ue iang | `H` | an in               | `I` | ong o iao un |
| `J` | ai iu uang    | `K` | iong m uan er eng v | `L` | ui ei        |


`v` = ü；`ue` 是 jue/que/xue 的韵母，`ve` 是 lve/nve 的韵母；`m`/`ng` 用于「呣、嗯」一类。

指法的省力程度分三档：`A` 最省力，`B`–`F` 次之（两指），`G`–`L` 再次（三指）。这就是为什么 A 指法上的一简要人工挑选（见后）。

### 取码规则



#### 单字：三码定长

```
单字全码 = 音节码 + 首字根码 + 末字根码
```


| 字   | 音节         | 首字根    | 末字根    | 全码       |
| --- | ---------- | ------ | ------ | -------- |
| 鸣   | míng `qF`  | 口 `vC` | 鸟 `aI` | `qFvCaI` |
| 想   | xiǎng `tG` | 木 `bB` | 心 `tI` | `tGbBtI` |
| 谢   | xiè `tB`   | 讠 `bG` | 寸 `wI` | `tBbGwI` |
| 放   | fàng `tA`  | 方 `tA` | 攵 `tH` | `tAtAtH` |


同偏旁的字第二码必然相同，这是形码部分带来的确定感：吃 `qEvC`、吗 `qGvC`、吧 `rGvC`、听 `zFvC`、叫 `vIvC`、鸣 `qFvC`——后面那个 `vC` 都是「口」。

#### 词：四码定长，全码六码

甲乙丙…表示词中各字，①②③ 表示该字的第 1 / 2 / 3 码。


| 词长   | 前四码（主码）     | 全码后两码 |
| ---- | ----------- | ----- |
| 二字   | 甲① 乙① 乙② 乙③ | 甲② 甲③ |
| 三字   | 甲① 乙① 丙① 丙② | 丙③ 甲② |
| 四字   | 甲① 乙① 丙① 丁① | 丁② 丁③ |
| 五字   | 甲① 乙① 丙① 丁① | 戊① 戊② |
| 六字以上 | 甲① 乙① 丙① 丁① | 戊① 末① |


- 一个 = 一① 个① 个② 个③ = `fE xF vD eC`，全码补 一②③ → `fExFvDeCsKfE`
- 动物园 = 动① 物① 园① 园② = `dI wC fK vJ`，全码补 园③ 动② → `dIwCfKvJeIfI`

**词的前两码永远是头两个字的音节码**，所以一次双手并击就把两个字的音一起打出来了——这是呦呦「一击两个字」的由来。

### 打法「四条通道」

沿用前文 `A/a/B/b/C/c` 的记法（大写不带 `Space`，小写带 `Space`；`A/a` 双手并击，`B/b` 左手单手，`C/c` 右手单手）。呦呦把四条通道分给了四件事：


| 通道        | 击键      | 一击出 | 用途                               |
| --------- | ------- | --- | -------------------------------- |
| `B` / `C` | 单手，不带空格 | 1 码 | **一简字**，直接上屏                     |
| `b` / `c` | 单手，带空格  | 1 码 | 第一击 → **一简词**，直接上屏；前面有码 → 补单字第三码 |
| `A`       | 双手，不带空格 | 2 码 | **打词**：一击两码，两击满四码，下一键顶屏上屏        |
| `a`       | 双手，带空格  | 2 码 | 第一击 → **单字前两码**；前面有码 → 补词的第五、六码  |


与纯形两套功法最要紧的两点不同：

1. `B`**/**`C` **与** `b`**/**`c` **不再按字形结构分工。** 纯形里 `b` 打 `⿰`/`⿺` 结构、`c` 打其他结构；呦呦左右手完全镜像等价，用哪只手纯看顺手。代价是少了一个结构筛选维度，收益是**同一个码元的四条通道能各挂一个不同的字/词**（见下节）。
2. **字词在第一击就彻底分流。** `A` 起手只出词，`a` 起手只出单字，`B`/`C` 只出一简字，`b`/`c` 起手只出一简词。四类编码互不重叠，不存在字词混选。



### 一简：700 个一击直出的字词

180 个码元 × 4 条通道 = **720 个一简槽位**，目前用掉 **700 个**（346 个字 + 354 个词），跨通道零重码，全部**一击直接上屏，不用空格、不用顶屏**。

- 单手不带空格（`B`/`C`）350 槽：346 个字，外加 4 个高频词（没有、我们、可以、所以）。
- 单手带空格（`b`/`c`）350 槽：全为词。
- 对照：纯形的一简字 + 一简词共 60 个。

同一个码元的四条通道各挂一个，互不干扰：


| 码元   | `_` 左手不带空格 | `+` 右手不带空格 | `<` 左手带空格 | `>` 右手带空格 |
| ---- | ---------- | ---------- | --------- | --------- |
| `dC` | 都          | 如          | 如果        | 如何        |
| `sD` | 好          | 号          | 好的        | 好像        |
| `vJ` | 开          | 久          | 就是        | 开始        |
| `dA` | 的          | 人          | 但是        | 都是        |


**其中 640 个不用死背。** 非 A 指法的 320 个一简字和 320 个一简词，编码正好等于它自己的首码元——也就是「打出这个字的音、或这个词头一个字的音，它就直接上屏」。上表的 `dC`（如 → 如果 / 如何）、`sD`（好 → 好的 / 好像）都是这个规律。

**只有 A 指法这 60 个是人工钉死的，建议背**（`A` 是最省力的指法，值得把最高频的字词放进来，所以故意打破了上面的规律）：


| 码元   | `_` | `+` | `<` | `>` |
| ---- | --- | --- | --- | --- |
| `qA` | 吃   | 没有  | 每天  | 模型  |
| `wA` | 我   | 我们  | 问题  | 味道  |
| `eA` | 是   | 上   | 使用  | 什么  |
| `rA` | 不   | 被   | 比较  | 不错  |
| `tA` | 小   | 下   | 需要  | 学习  |
| `aA` | 中   | 你   | 这个  | 知道  |
| `sA` | 和   | 很   | 还是  | 很多  |
| `dA` | 的   | 人   | 但是  | 都是  |
| `fA` | 有   | 一   | 一个  | 因为  |
| `gA` | 在   | 去   | 自己  | 其他  |
| `zA` | 他   | 她   | 他们  | 通过  |
| `xA` | 更   | 个   | 公司  | 感觉  |
| `cA` | 了   | 来   | 里面  | 了解  |
| `vA` | 就   | 可以  | 进行  | 技术  |
| `bA` | 而   | 所以  | 而且  | 安全  |




#### 例子：打单字（以「鸣」为例）

已知 `鸣 = qF vC aI`（音 míng + 口 + 鸟）。

1. 第一击：`a`（双手带空格）出前两码 `qFvC`。两码层 4684 字**零重码**，「鸣」此刻已经唯一。
2. 继续输入下一键触发顶屏，「鸣」上屏。

若这个字不在两码层的 4684 个之内，就要补第三码。以「放」为例，两码 `tAtA` 被更高频的「方」占了：

1. 第一击：`a` 出 `tAtA` → 首选是「方」。
2. 第二击：`b` 或 `c` 补第三码 `tH`（哪只手都行）。
3. 继续输入下一键触发顶屏，「放」上屏。

**单字最多两击。** 346 个一简字只需一击（`B`/`C`），且直接上屏。

#### 例子：打词（以「动物园」为例）

已知「动物园」主码 `dI wC fK vJ`，全码 `dIwCfKvJeIfI`。

1. 第一击：`A`（双手不带空格）出 `dIwC`——「动」「物」两个字的音一起出来了。
2. 第二击：`A` 出 `fKvJ`，满四码。四码层**零重码**，此刻唯一。
3. 继续输入下一键触发顶屏，「动物园」上屏。

短词常常一击就够：「中国」`aIxB`、「世界」`eEvB`、「以及」`fEvE`，一次双手并击即满两码。

需要精确到全码时，第三击用 `a`（双手带空格）补末两码 `eIfI`。若候选不是首选，按 `'` 选二选并立即上屏。

**词最多三击。** 354 个一简词只需一击（`b`/`c`），且直接上屏。

### 音形的码位是算出来的

A 指法（最省力的 15 个码元）上那 60 个一简，以及整套声母键位、韵母指法的分组，都不是手排的，而是用 `[scripts/声韵母按权重重排键位指法/](rime/scripts/声韵母按权重重排键位指法/)` 里的脚本按字词权重穷举搜索出来的：目标是最大化 `Σ(权重 × 按键容易度)`。该目录的 README 说明了码位分层模型、顺延（被挤出的字词降到更长码）与补位（腾空的码位从更长码提上来）的完整算法。

目前仍空缺的码元：`sE` `xE` `fB` `fJ` `fL`（这 5 个码元在字表词表里都没有候选）。这个结论是可验证的——`practice_tool/generate_yx_data.py` 会把 `yoyo.yaml` 里的「折梅」规则整套展开，逐一检查字表词表用到的每个码元能否打出来，并报告哪些码元有指法但没候选。跑出来正好是这 5 个，与上面手工统计一致。

> 这项校验顺带查出过一个真 bug：「折梅」里一组为 195 码元设计的 `M` 规则，其两键组合是若干 `A`–`L` 三键组合的子集，且排在前面，会把 `aK` `gJ` `sJ` `xJ` `zK` 这 5 个码元吃掉，连带 420 个字、16.8 万个词打不出来。字表词表一个 `M` 码元都没用到，所以已在 `yoyo.yaml` 中整块停用，停用后恰好是 15×12=180 个码元，与方案设计一致。**用过早于此修复版本的** `yoyo.yaml` **的话，请整体覆盖更新。**

| [practice.html](practice_tool/practice.html)       | 纯形字根：看到字根打出它的大码小码                        |
| [practice-yx.html](practice_tool/practice-yx.html) | 音形并击：码元指法（180）/ 字根（466）/ 一简直出（700）/ 单字全码 |


音形那个页面在浏览器里复刻了一次「击」的判定——同时按下的键算作一击，全部松开才结算，所以按键先后顺序不影响结果，练的是真并击而不是逐字母敲。默认不点亮键位（否则等于替你记住了指法），按 `Enter` 才看答案，按 `Tab` 跳过。

一简模式会额外校验**通道**：哪只手、带不带空格都得对，因为同一个码元的四条通道挂着四个不同的字词。单字模式走真实路径：双手带空格出前两码，需要时再单手带空格补第三码。

## 网站部署和查看

[luming-input_full_website](luming-input_full_website/) 是该输入法的介绍网站，顶部菜单把两条分支分成两个独立页面：

- `/`：纯形·麓鸣，含纯形规则、字根表与练习工具。
- `/yinxing`：音形·呦呦，含音形规则、180 码元字根表与并击练习。
- `/benchmark`：纯形 / 音形重码对照与简码击数测评；重码数字可悬停查看具体编码与字词，击数表按频序展示一击、二击、三击覆盖。

`pnpm dev` 和 `pnpm build` 会先同步音形字根表、练习器和共用字根图片，并从
`rime/yoyo-bm.dict.yaml` 重新计算纯形测评，再与已打包的音形 Chai 测评快照合成对照数据；
简码击数表同时保留同词库的 Chai 横向对照和发布版白霜音形结果。单独复制网站目录部署时，
则直接使用已打包的资源与测评数据。其 `docs` 目录下的[部署说明](luming-input_full_website/docs/README_How_to_deploy.md)包含完整方法。

## 编码和派生文件怎么重新生成

音形的拆分输入、完整基础词库和生成脚本都在仓库内。下面各命令均不需要额外参数。

```bash
# 1. 拆分 + 拼音 + 149 万词 → 初始字词编码、Rime 字典、重码报告
python3 "rime/scripts/编码生成和重码可视化/main.py"

# 2. 字根 → 码元的映射，以及单字拆分表；
#    与上一步共读 rime/scripts/编码生成和重码可视化/data/elements.txt
#    8105 个字互相交叉验证，出现任何冲突就报错退出，所以这份表不会悄悄错
python3 zigen_table/generate_yx_mapping.py

# 3. 展开 yoyo.yaml 的「折梅」规则 → 练习数据 + fingering-yx.json
#    同时校验字表词表用到的每个码元都打得出来，打不出来会直接报错退出
python3 practice_tool/generate_yx_data.py

# 4. 音形字根表 HTML（读上面两步的产物）
python3 zigen_table/generate_yx_html.py

# 5. 把上面两份页面及其依赖同步进介绍网站
node luming-input_full_website/scripts/sync-yx-assets.mjs
```

第 1 步输出的是**声韵母重排和 A 位处理前的初始字典**，不能直接覆盖发布词库；完整的后续顺序、输入输出和裁剪命令见
`[编码生成和重码可视化/README.md](rime/scripts/编码生成和重码可视化/README.md)`。

第 3 步是有意设计成会失败的：一旦指法规则和字典对不上（比如某个码元被别的规则遮蔽），它会列出打不出来的码元并以非零码退出，而不是默默生成一份错的数据。上面那个 `M` 规则的 bug 就是这么发现的。
