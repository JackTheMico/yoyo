# yoyo-pure-km：一击（一次并击）可打出的字词数量

> 调查目标：在麓鸣·纯形·空明（yoyo-pure-km）方案下，有多少种「字词」可以**只按一击**（一次并击 / 一个 chord）就上屏。
> 数据源：`rime/yoyo-pure.dict.yaml`（主词表）、`rime/yoyo-user.dict.yaml`（用户加词表）、`rime/yoyo-pure-km.schema.yaml`（心法/键盘）、`rime/lua/yoyo/data/pure_dict_map.lua`（运行时映射）。
> 统计脚本：`research/count_one_stroke.py`（与既有 `analyze_kongmingmas_one_chord.py` 的「净码长」口径一致）。

## 1. 口径说明

在纯形统一流（0 空格）模型里，一次「击」= 一次并击（chord）。经 chord_composer 代数链仿真验证（见 `analyze_kongmingmas_one_chord.py`）：

- **净码长 = 去掉 `_`/`+`/`'` 后的字母数**。`净码长 ≤ 2` ⇔ 只需一次并击即可上屏（1 键单手、或左右手 2 键并击）。
- `净码长 ≥ 3`（如 3 码单字 = 2 击、4 码词 = 2 击）不计入。

「一击」在本项目中存在三种常见口径，结论分别如下。

## 2. 三种口径的结论

### A. 字面口径：所有「一次并击即上屏」的字词（单字 + 多字词 + 空格简词）

| 类别 | 数量 | 说明 |
|---|---|---|
| 单字一击 | 2805 | 1 码一简 120 + 2 码二简等 2712 |
| 多字词一击（净码长 ≤2） | 3563 | 净码长 1 的 120（`_X`/`+X` 简词，如 可以/我们）+ 净码长 2 的 3443（如 这种`VZ`/以及`y<`） |
| 空格并击简词（`%XY`/`%_X`/`%+X`） | 995 | 双手+空格 876、左手+空格 59、右手+空格 60 |
| **合计（去重，三集合两两不交）** | **7363** | |

### B. 项目约定口径：仅「多字词」一击词（既有报告口径）

- 既有 `km_one_chord_words_recommend.md` 定义为「净码长 ≤2 的**多字词**一击词」，当时记为 **3566**。
- 用当前字典重算（仅多字词、`net_len≤2`、非 `%` 码）：**3563**，与既有报告基本一致（差异 3 条来自字典后续增删，如手动加词段）。
- 这是与本仓库既有研究**直接可比**的数字。

### C. 设计型「一击捷径」口径（区别于普通 2 码词）

以下两套是方案**专门设计**的一击捷径（不需要记 2 码组合，纯单手/空格并击肌肉记忆）：

| 子类 | 码位数 | 候选字词 | 说明 |
|---|---|---|---|
| 单手一击一简（`_X`/`+X` 单键） | 120（左 60 / 右 60） | **240**（120 单字 + 120 词） | 每个码位挂 2 候选：如 `_d`→的/其他、`_x`→和/可以 |
| 空格并击简词（`%` 码） | 995 | 995 | 一击上屏，如 记忆`%u:`/提交`%iZ` |
| **合计** | 1115（码位） | **1235**（候选） | |

> 注意：一简的 120 个单字、120 个 2 字简词**已包含在口径 A/B 中**（属于净码长 ≤2 的子集）；空格简词（`%` 码）是独立的 995 个。

## 3. 结论速查

- 若问「**所有一次并击就能打出的字词**」：**7363** 个（2805 单字 + 3563 多字词 + 995 空格简词）。
- 若沿用本仓库既有研究的「**一击词**」定义（多字词、净码长 ≤2）：**3563**（≈ 报告 3566）。
- 若指方案**专门设计的一击捷径**（一简 + 空格简词）：**1235** 个候选（1115 个码位）。

## 4. 复算方法

`research/count_one_stroke.py`：
- 字典列顺序经 `yoyo-pure.dict.yaml` 头部 `columns: [text, code, weight]` 确认。
- `net_len(code) = len(code.replace("_","").replace("+","").replace("'",""))`；一击判定 `net_len ≤ 2`。
- 空格简词单独判定「首字符 `%` 且码长 3」，并与运行时 `pure_dict_map.lua` 的 `space_brief_map`（995 条）交叉校验一致。
- 一简「候选级 240」来自 `yoyo-pure.dict.yaml` 中 120 个 `_X`/`+X` 码位各挂 2 个候选（单字 + 词）的事实。
