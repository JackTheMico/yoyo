🦌 呦呦简词并击练习

练习「前置单引号简词」：先点按-松开 '，再并击打出两个码元—— '_X 左手一击、'+X 右手一击、'XY 左右两手并击。 编码规则是' + 字1首根 + 字2首根（如 最多 = 最w + 多S → 'wS），所以练简词等于同时练字根拆解。 实际输入中第 2 击之后再接任意下一键即顶出上屏，练习中打完两击即算对。 与「' 同按 = 次选」靠时序天然分流，互不影响。

空格并击（一击上屏）
' 前缀（两击）

怎么用

空格并击（一击上屏）：空格与码元键同时按下即算一击，全部松开才结算—— %XY 双手+空格、%_X 左手+空格、%+X 右手+空格，打完直接上屏。
' 前缀（两击）：第 1 击单独点 '，第 2 击并击码元， 实际输入中再接任意下一键顶出上屏（练习里打完两击即算对）。
按 Enter 看答案并点亮键位（这一题不再计入「一遍过」），按 Tab 跳过。 答错时也会自动点亮键位。默认不点亮，否则等于替你记住了指法。

间隔重复

采用间隔重复：答对的题按 2 → 4 → 8 → 12 → 20 → 40 → 60 → 100 的间隔往后排， 连续答对 3 次算「已掌握」；答错或跳过的题计数归零，很快会再出现。 进度自动存在浏览器里（与主练习页分开保存），刷新不丢。

码形速记（两套编码同一套字根规则）

%XY / 'XY两手同时并击：左手打 X、右手打 Y（如 最多 %wS / 'wS：左手 w、右手 s+d 打 S）
%_X / '_X只用左手一击打出码元 X（如 这种 %_v：左手 v + 空格）
%+X / '+X只用右手一击打出码元 X（镜像键位，如 看起来 %+i）
